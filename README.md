# Bank Customer Churn Prediction Website (Matplotlib)

## Files
- `app.py` — Streamlit website, using Matplotlib for every graph and confusion matrix.
- `requirements.txt` — Python dependencies.
- `BankChurners.csv` — dataset.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

Keep all three files in the same folder. The website runs at the local URL shown in the terminal.

## Deploy
Upload the files to a GitHub repository, then create an app at https://share.streamlit.io/ with `app.py` as the main file.

## Important
This is an educational demonstration. Check recall for attrited customers as well as accuracy. Do not publish confidential customer data.
